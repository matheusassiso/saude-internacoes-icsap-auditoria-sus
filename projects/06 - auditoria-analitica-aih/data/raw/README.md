Raw data are generated by `src/R/aih_audit.R`.

Sources:

- SIH/SUS reduced AIH files (`RD`) for Mato Grosso do Sul, downloaded with `datasusr`.
- IBGE municipality list for Mato Grosso do Sul.
- `geobr` municipality geometries for map outputs.

Generated raw CSV files are ignored by Git because they can be rebuilt from public sources.
